Pick the catalogue brands you follow, sort the catalogue by series, find your own spools by colour, and scroll your plans with the mouse wheel. Ghost racks are gone for good.

## New

- **Catalogue brands.** The catalogue asks which brands you follow and shows only their products. Change the list any time with the brands button in the toolbar; untick everything to start over.
- **Sort by series.** The catalogue can be sorted by series, so every colour of the same filament sits side by side.
- **Find by colour in your inventory.** The colour button is now in the search bar of your inventory (grid, table and storage). Pick a colour, a RAL code or a point on a photo: the closest spools come first, the others are hidden (dimmed in storage).

## Improved

- **Colour search card.** The colour picker shows straight away and follows the colour chosen from the presets, the HEX field, a RAL code or a photo. Explanations moved into ⓘ bubbles, and multicolour spools are counted by default.
- **Plans.** On the storage plan, the printers plan and the camera wall, the mouse wheel scrolls and Ctrl / ⌘ + wheel (or a pinch) zooms; Ctrl / ⌘ + and − zoom too.
- **Search bar.** The magnifier is gone; the QR, filter and colour buttons stay in place while you type.
- **Lighter on the server.** Studio reads and writes much less to the TigerTag servers at launch and when opening histories.
- Reference data refreshed: 24,865 products in the catalogue.

## Fixed

- Fixed an issue where empty "undefined · 0/NaN" racks kept coming back in Storage. Existing ones are removed automatically.
- Fixed an issue where the maker's logo was missing on some label layouts (vertical labels, Slicer label), or printed without its letters.
- Fixed an issue where the colour search button was missing from the search bar at launch.
- Fixed an issue where importing a `.ttag` file in Import mode always failed.
- Fixed an issue where a Feitian licence dongle was listed as an RFID reader.
- Fixed an issue where an empty dark box showed at the right of the header in a friend's view.
- Fixed an issue where editing a filament on a Klipper printer did not count for its mission.
- Fixed an issue where the Favorites view could flicker.
