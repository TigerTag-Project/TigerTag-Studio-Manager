Two new languages, contributed by the community.

## Added

- **Russian** and **Dutch** — the app is now available in 11 languages. Both were contributed by a community member and reviewed string by string before shipping. Pick yours in your account settings.

## Changed

- Debug mode can now be turned on by anyone, from the account settings. It shows what the app sees — your own data, the last call to the server — which is exactly what a useful bug report needs.
- Fixed a case where a long translation was cut off in the printer speed selector.
