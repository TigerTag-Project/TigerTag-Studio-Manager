A fix that keeps the catalogue refresh from overloading the TigerTag API, and the Bambu Lab A2L recognised when added by IP.

## Fixed

- **Catalogue refresh.** Studio 2.59.0 and 2.59.1 asked the TigerTag API about the same spools over and over, which overloaded it. Studio now checks your spools against the catalogue only when the catalogue has actually changed, asks about each spool once per change, at most 10 at a time, and backs off when the API is struggling. Updating is recommended.
- **Bambu Lab A2L.** An A2L added by its IP address is recognised from its serial number instead of asking you to pick the model.
