Print labels over Bluetooth, steadier Bambu Lab cameras, and Anycubic Cloud session warnings.

## New

- **Bluetooth label printing.** Print a spool or filament label straight to a Niimbot, Phomemo or Marklife label printer from the label card. Studio remembers your default printer and the roll used with each model.
- **Labels in a batch.** Select several spools, choose "Labels" in the selection bar and print them all in one go. If printing stops, you can resume from the next label.
- **Bambu Lab P3C.** The P3C is now recognised, with its seven tools and its AMS 3P.
- **Anycubic Cloud session warning.** Studio warns you before your Anycubic Cloud session ends. Once it has ended, a "Session expired" notice appears with a Reconnect button.
- **Diameter filter.** The Diameter filter now also works in the catalogue and in the products and Lists views.
- Printing and exporting labels (PDF, PNG, SVG) is now always done at 300 dpi; the 203 / 300 dpi switch has been removed.

## Fixed

- Fixed an issue where the live view of Bambu Lab X1C, X1E, P2S and H2 cameras showed the same picture for several seconds.
- Fixed an issue where a Bambu Lab camera could stay frozen after a few minutes and not restart until Studio was relaunched.
- Fixed an issue where the Anycubic Cloud camera stayed black without saying that the session had expired.
- Fixed an issue where a Snapmaker U1's job and loaded filament were not available to the AI assistant until a Printers view was opened.
- Fixed an issue where adding a product already covered by your stock to the cart did not list it.
- Fixed an issue where a "Microsoft IFD" reader on Windows could keep the chip writing window waiting.
- Fixed an issue where the TigerCoins balance on the Deals banner did not update after sending coins.
- Fixed an issue where a RAL code declared by the brand was ignored in the catalogue colour search.
- Fixed an issue where the colour bars and the colour search could be combined and look like a broken filter.
- Fixed an issue where the empty catalogue message with filters on was confusing.
- Reference data refreshed: brands and products in the catalogue.
